GameSpec Website
================

Files:
- index.html — complete website. No external libraries or assets are required.

How to test:
1. Open index.html in Chrome/Edge.
2. Enter a CPU.
3. Choose Dedicated GPU and enter a GPU, OR choose Integrated / None.
4. Select RAM, resolution and graphics preset.
5. Click Analyze My PC.
6. Search games in the results panel.

Upload:
For most static website hosts, upload index.html to the site's public/root folder.
Because the website is currently self-contained, no other files are required.

Note:
FPS results are estimates based on the built-in game/hardware model. They are not real benchmark measurements.
